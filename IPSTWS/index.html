Орден Джедаев и Сила

Сила — это энергетическое поле, создаваемое всеми живыми существами. Она окружает нас, проникает в нас и связывает галактику воедино. Изучение Силы открывает невероятные возможности для тех, кто готов следовать по пути света или поддаться искушению темной стороны.

Основные принципы Кодекса:

  • Нет волнения — есть покой.
  • Нет невежества — есть знание.
  • Нет страсти — есть безмятежность.
  • Нет хаоса — есть гармония.
  • Нет смерти — есть Сила.
